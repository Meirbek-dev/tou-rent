# Документы офлайн-комиссии

Загрузка доступна секретарю после вскрытия конвертов. Она не заменяет
электронное голосование, не меняет статус тендера или заявки и не создаёт договор.

## Общий протокол

1. Откройте тендер в кабинете секретаря → «Протоколы».
2. В блоке «Документы комиссии» нажмите «Загрузить документ».
3. Укажите название, номер (или «б/н»), дату и выберите PDF до 10 МБ.
4. После загрузки проверьте файл по ссылке. Пока он скрыт от участников.
5. Откройте доступ участникам отдельной кнопкой и подтвердите действие.

Общий документ будет доступен владельцам заявок этого тендера в карточках
их заявок. На публичной странице для незарегистрированных посетителей он не появляется.

## Документ конкретному участнику

1. Откройте вкладку «Заявки» в кабинете секретаря.
2. В строке нужной заявки нажмите «Документы участнику».
3. Проверьте номер лота и заявителя в заголовке окна.
4. Загрузите PDF с названием, номером и датой, затем отдельно откройте доступ.

Такой документ увидит только владелец выбранной заявки, а не другие участники.
В его кабинете нужно открыть соответствующую заявку → «Документы комиссии».
Автоматическая рассылка уведомлений о новых файлах пока не предусмотрена.

## Исправления и хранение

Доступ можно закрыть. Уже скачанные копии при этом не отзываются.
Оригинальный файл не перезаписывается: исправленный документ загружается отдельно.
Загрузка и изменение доступа фиксируются в аудите, файл включается в досье.
Системные PDF-протоколы сохраняются отдельно и помечаются как сформированные системой.

## Обновление сервера

Изменение включает интерфейс, API и новую таблицу с миграциями
`20260914120000_commission_documents.sql` и
`20260914121000_commission_document_guards.sql`. Обновить только web недостаточно.
Перед production-развёртыванием нужны штатная резервная копия и проверка миграции
на копии актуальной базы. Файлы документов загружаются секретарём после обновления;
сами документы в Git не включаются.
