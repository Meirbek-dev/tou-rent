# GAUNTLET — журнал прогона на производственную готовность

Формат: `G-NNN | круг | измерение | важность | доказательство | статус`.
Статусы: `open` → `fixed` (перепроверено свежим критиком) / `wontfix-logged`
(вне области, нужен человек) / `blocked` (три стратегии не помогли).

Область и границы — `.claude/commands/gauntlet.md` (§1 цель, §2 метрика,
§3 границы). Критик и исполнитель — всегда разные контексты: находку
закрывает не тот, кто ее чинил.

### Происшествие круга 1 (испорченные данные стенда)

Проверяя G-006, я выполнил `TRUNCATE` по живой базе стенда, а не по
одноразовой копии, как требует § 3 регламента. Первая редакция миграции
фильтровала триггеры по биту 8 (`DELETE`), а не 32 (`TRUNCATE`), поэтому
ни одного сторожа не создала — и четыре `TRUNCATE` прошли:

| Таблица                | Было | Стало |
| ---------------------- | ---- | ----- |
| `audit.log`            | ~90k | 0     |
| `core.bids`            | ?    | 0     |
| `core.ledger_entries`  | ?    | 0     |
| `core.journal_entries` | ?    | 0     |

Данные невосстановимы: цепочка аудита стенда стерта. Уцелели
`tenders` (154), `applications` (121), `users` (247), `contracts` (8) —
то есть стенд сейчас несогласован: договоры без проводок, заявки без
журнала. Прод и код не затронуты; потеряны только данные дев-стенда,
который по замыслу пересоздаваем.

Восстановление — пересборка стенда с нуля (том `pg_data` удаляется):

```
vp run stack:down && podman volume rm tou-rent-dev_pg_data && vp run stack:up
```

Сама находка G-006 после исправления бита проверена уже правильно —
в одноразовой `gauntlet_tr`, которая затем удалена.

### Снятые гипотезы (доказательство убило находку)

- Просроченный срок в плитке «Ближайшие сроки приема заявок» — не дефект:
  `deadlineUrgency` имеет состояние `overdue`, тон плитки берется от него,
  показ просроченного срока организатору намеренный (`lib/relative-time.ts:49`).
- «99+» и отсутствие пагинации в списке тендеров организатора — не потолок:
  `MAX_ROWS = 1000`, а в списке 99 реальных черновиков. Настоящая проблема
  рядом и в G-001 — не в самом потолке, а в том, что о нем молчат.

### Вне области (нужен человек, зафиксировано)

- Коэффициенты Прил. 4 и МРП засеяны фиктивными `1.0000` / `9999` —
  нужен текст Правил (Q/A-010).
- Тела юридических форм в `crates/http/src/templates/*.typ` — формулировки
  приложений Правил (Q-004/005/014/017).
- Состав демо-комиссии (п. 9–11), внешние каналы уведомлений FR-1303 (T41).
- Казахские формы 11 ключей `rate_coef_*`: комментарий
  `components/rate-fields.tsx:27` прямо говорит, что «Копф» читается на kk
  иначе, чем на ru — нужен носитель языка, транслитерация наугад запрещена.
- `specs/BACKLOG.md`: T41 записан дважды (строки 415 и 502) — учетная запись,
  на код не влияет.
