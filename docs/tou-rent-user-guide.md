## 1. Что это за сайт

Университет сдаёт в аренду свои помещения, здания, сооружения и земельные
участки. По правилам университета это делается не по договорённости, а через
открытую процедуру: объявление, приём заявок, работа тендерной комиссии,
онлайн-торги на повышение и заключение договора с победителем.

ToU Rent - платформа, где эта процедура проходит целиком:

- университет публикует объявления о тендерах и список свободных площадей;
- любой желающий видит условия, сроки и документацию, не входя в систему;
- участники подают заявки через сайт и торгуются онлайн;
- комиссия вскрывает заявки, принимает решения и голосует в системе;
- документы - объявление, протоколы, договоры, акты - формируются
  автоматически в виде готовых PDF;
- результаты публикуются на портале и доступны шесть месяцев.

## 2. Открытая часть: что видно без входа

Регистрация нужна только чтобы **участвовать**. Чтобы **смотреть** - не нужна.

| Раздел                | Что там                                                                                                                                                                     |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Главная**           | Актуальные объявления, портал в цифрах (сколько объявлений, сколько принимают заявки, сколько свободных объектов и участков), краткое объяснение процедуры                  |
| **Тендеры**           | Реестр всех объявлений с фильтрами по названию и статусу и постраничным просмотром                                                                                          |
| **Карточка тендера**  | Сроки, лоты, стартовые ставки, размер гарантийного взноса, тендерная документация, PDF объявления, изменения условий, опубликованные протоколы                              |
| **Свободные площади** | Реестр объектов университета: вид имущества, адрес, площадь, статус (свободен / выставлен на тендер / сдан). Фильтры по виду, статусу, площади и поиск по названию и адресу |

| **Особый порядок**    | Публикации по заявкам, рассмотренным без тендера: результат, обоснование ставки, акты приёмки инвестиций                                                                    |
| **Как участвовать**   | Пошаговое объяснение процедуры для новичка                                                                                                                                  |

### Что важно знать про публикации

- Объявление публикуется так, чтобы **до вскрытия конвертов оставалось
  не менее 10 календарных дней**. Раньше система опубликовать не даст.
- Протоколы доступны публично **шесть месяцев**, затем автоматически
  снимаются с публикации. Сам документ при этом не пропадает - он остаётся
  в досье тендера.
- Изменения тендерной документации и отмена тендера публикуются здесь же,
  а участники получают уведомление.

## 3. Регистрация и вход

### Регистрация участника

Нужны три вещи: имя, адрес электронной почты и пароль **не короче
12 символов**. Сведения о юридическом или физическом лице (реквизиты,
БИН/ИИН, телефон) заполняются позже - в мастере подачи заявки, а не при
регистрации. Сразу после регистрации вы оказываетесь в кабинете участника.

### Вход

Вход по адресу почты и паролю.

### Если пароль забыт или скомпрометирован

- **Забыли пароль** - обратитесь к администратору портала. Он выдаст
  одноразовый пароль, который показывается ему один раз; смените его сразу
  после входа.
- **Сменить пароль** можно на отдельной странице рядом со входом. Текущий
  пароль спрашивается обязательно - это защита на случай, если за ваш
  незакрытый компьютер сел посторонний.
- Кнопка **«Выйти»** - в меню учётной записи внизу бокового меню. Если вход
  был через корпоративную учётную запись, выход завершает и её сессию: иначе
  на общем компьютере следующий вход прошёл бы молча.

## 4. Как устроен личный кабинет

После входа интерфейс одинаков для всех, меняется только наполнение.

**Слева - боковое меню.** Оно сгруппировано по ролям: сначала общая группа
«Рабочее место» (Обзор, Уведомления, при наличии прав - Отчётность), затем
по группе на каждую вашу роль. Один человек может быть одновременно,
например, организатором и членом комиссии - это разные обязанности с разными
сроками, поэтому и разделы разные. Рядом с пунктами меню показываются
счётчики: сколько дел ждёт именно вас.

**Сверху - панель:**

- **Breadcrumbs** - где вы сейчас находитесь;
- **командная палитра** - поиск по разделам, чтобы перейти куда угодно
  в два нажатия, не разворачивая меню;
- **«Мои сроки»** - ближайший срок по Правилам и общее их количество;
- **колокольчик уведомлений** со счётчиком непрочитанных.

**Страница «Обзор»** - первое, что вы видите. Она собирает по всем вашим
ролям сразу: что требует внимания, ваши очереди, ближайшие сроки и последние
уведомления. Если делать нечего, она честно пишет: «Очередей нет - ничего
не ждёт вашего решения».

**Ошибки объясняются по-человечески.** Если система отказала в действии,
она пишет причину словами Правил: не «ошибка 409», а, например, «Срок приёма
заявок истёк - состав заявки больше не меняется» или «Ставка ниже минимально
допустимой: нужен текущий максимум плюс шаг торгов».

**Необратимые действия подтверждаются диалогом**, в котором прямо написано,
что произойдёт и что это нельзя отменить.

## 5. Роли и кабинеты

Роль - это не звание, а рабочее место. Роли назначает администратор, и каждое
назначение записывается в журнал.

| Роль                   | Кто это                       | Чем занимается на портале                                                      |
| ---------------------- | ----------------------------- | ------------------------------------------------------------------------------ |
| **Участник**           | Внешний арендатор, инвестор   | Подаёт заявки, торгуется, подписывает договоры                                 |
| **Организатор**        | Подразделение, ведущее аренду | Ведёт объекты, создаёт и публикует тендеры, считает ставки, ведёт договоры     |
| **Секретарь комиссии** | Секретарь тендерной комиссии  | Ведёт журнал регистрации, вскрывает конверты, оформляет протоколы, ведёт торги |
| **Член комиссии**      | Член тендерной комиссии       | Голосует по допуску заявок, декларирует конфликт интересов                     |
| **Финансы**            | Оператор финансового блока    | Подтверждает гарантийные взносы, ведёт депозитную книгу и возвраты             |
| **Правление**          | Правление университета        | Принимает решения по особому порядку и земельным участкам                      |
| **Администратор**      | Администратор портала         | Ведёт пользователей и роли, справочники, следит за целостностью журнала        |

## 6. Кабинет участника

### Обзор

Ход ваших заявок и тендеры, в которых приём ещё открыт, - на одной странице.

### Подача заявки

1. Найдите тендер с открытым приёмом заявок и откройте его карточку.
2. Нажмите «Подать заявку» на нужном лоте.
3. Заполните мастер: сведения о юридическом или физическом лице
   (наименование, БИН/ИИН, телефон), квалификационные сведения, приложите
   документы.
4. Укажите **ценовое предложение** - вашу стартовую цену.
5. Проверьте сводку и подтвердите.

**Ваша цена запечатана.** До момента вскрытия конвертов её не видит никто -
ни организатор, ни администратор портала. Это свойство хранилища: цена зашифрована ключом тендера.

**Приём строго до срока.** После дедлайна система заявку не примет и не
позволит изменить уже поданную. Часы - серверные, а не на вашем компьютере.

**Гарантийный взнос** равен месячной стартовой ставке лота и вносится
не позднее чем за два рабочих дня до первого этапа. В карточке лота сумма
указана явно. После поступления денег финансовый блок отмечает это в системе,
и статус вашей заявки меняется на «взнос подтверждён».

### Отзыв заявки

Пока приём открыт, заявку можно отозвать - отзыв фиксируется в журнале
регистрации с точным временем. После дедлайна отзыв невозможен.

### «Мои заявки»

Список ваших заявок со статусами: подана → взнос подтверждён → допущена
либо отклонена → отозвана. По отклонённой заявке видно основание из закрытого
перечня Правил.

### Участие в торгах

Если комиссия вас допустила, приходит уведомление: дата, время торгов и
**стартовая ставка** - она равна наибольшему из первоначальных предложений
допущенных участников по этому лоту. Ссылка на Zoom-конференцию есть
в карточке торгов.

В комнате торгов:

- **шаг ставки - 5 %** от стартовой ставки, он зафиксирован и виден в панели;
- **таймер 60 минут** с момента объявления старта председателем; продлить его
  можно **один раз на 15 минут** и только решением председателя;
- ставки идут **по кругу**: система показывает, чей сейчас ход, и вы либо
  повышаете, либо пасуете - пас означает выбытие из торгов по этому лоту;
- лента ставок обновляется у всех в реальном времени;
- если связь оборвалась, вернитесь в комнату - состояние восстановится,
  ваша уже принятая ставка не задвоится;
- индикатор соединения показывает, есть ли связь с сервером.

Торги идут, пока не останется один участник. Результат - победитель и
участник № 2 с их ставками. После завершения секретарь может добавить ссылку
на запись торгов - она видна участникам лота.

### Протоколы

«Протоколы моих тендеров» - копии протоколов по вашим заявкам в виде PDF.

### Договоры

Раздел «Мои договоры» показывает договоры, полученные по итогам торгов,
с текущим этапом конвейера: договор составлен → экземпляр передан → документы
для сверки представлены → сверка завершена → подписан наймодателем → вы
вернули подписанный экземпляр → зарегистрирован. Здесь же - печатная форма
договора, чек-лист документов для сверки, загрузка скана подписанного
экземпляра и акты приёма-передачи и возврата.

**Важно про сроки.** Победитель возвращает подписанный договор в отведённый
срок. Если этого не произошло, фиксируется уклонение: гарантийный взнос
удерживается, вы попадаете в реестр уклонившихся, а право на договор переходит
к участнику № 2. Заявки лиц из реестра уклонившихся отклоняются в будущих
тендерах автоматически.

### Заявка в особом порядке

Кроме тендера есть путь без торгов - см. [раздел 14](#14-особый-порядок-аренда-без-тендера).
Подаётся из кабинета участника: категория из перечня, цель использования,
обоснование и документы.

## 7. Кабинет организатора

### Обзор

Состояние реестров (черновики тендеров, приём заявок, свободные объекты,
объекты в тендере) и ближайшие сроки приёма заявок.

### Объекты

Реестр имущества университета: здания, помещения, сооружения, земельные
участки. У объекта - наименование, вид, адрес, площадь, этаж или часть здания
и характеристики, нужные для расчёта ставки.

**Статус объекта не редактируется руками** - он вычисляется из тендеров
и договоров: свободен, выставлен на тендер, сдан в аренду. Объект,
участвующий в лоте или договоре, удалить нельзя. Система не допускает двух
пересекающихся по времени аренд одного объекта.

### Калькулятор ставки

Считает арендную плату по методике Приложения 4 Правил:

```
Ап = Рбс × S × (Кт × Кк × Кск × Кр × Квд × Копф × Кфу × Ксоц × К × Кн / Кв)
```

Базовая ставка - **1,5 МРП за м² в год**. Калькулятор показывает не только
итог, но и **каждый множитель с расшифровкой** - расчёт можно объяснить
проверяющему. Отдельно выводятся ставка за год, ставка в месяц и размер
гарантийного взноса. Тиыны округляются: меньше 50 - отбрасываются, 50 и
больше - до тенге. НДС в базовую ставку не входит и помечается отдельно.

Есть **почасовой расчёт**: считается от 2 МРП за час по коэффициентам, площадь
в расчёт не входит; если коэффициенты опускают ставку ниже 2 МРП/час,
применяется этот минимум, и система об этом прямо пишет.

Справочники МРП и коэффициентов версионируются по дате вступления в силу.
Расчёт берёт версию на нужную дату, а в лоте тендера **замораживается снимок
расчёта** - правка справочника задним числом не меняет прошлые расчёты.

### Тендеры

Создание тендера: название, лоты из объектов, по каждому лоту - целевое
назначение, срок найма, вид аренды (помесячная или почасовая), базовая ставка
из калькулятора, гарантийный взнос, условия осмотра объекта.

Дальше - сроки: дата вскрытия конвертов, дедлайн приёма заявок, дата торгов,
ссылка на Zoom. Затем публикация. **Если до вскрытия остаётся меньше
10 календарных дней, система откажет в публикации и объяснит причину.**

Статусы тендера: черновик → объявлен → приём заявок → вскрытие и допуск →
торги → итоги подведены → договор заключён. Боковые ветки: не состоялся,
повторный тендер, отменён. Переходы возможны только те, что предусмотрены
Правилами.

**Изменение условий.** Пока приём открыт, документацию можно изменить -
создаётся новая редакция, дедлайн продлевается, участники получают
уведомление, изменение публикуется на портале.

**Отмена.** Тендер или отдельный лот отменяются с указанием основания;
участники извещаются, отмена публикуется. После заключения договора отмена
невозможна.

### Признание несостоявшимся

Система сама определяет основание: не подано ни одной заявки; подана
единственная заявка; допущено менее двух участников; победитель и участник
№ 2 уклонились. Организатор формирует протокол о несостоявшемся тендере (PDF)
и выбирает следствие: повторный тендер (черновик создаётся одной кнопкой),
договор из одного источника по решению комиссии либо передача вопроса
Правлению.

### Договоры и акты

Договор формируется из типовой формы по данным протокола; существенные
условия берутся из результатов торгов и **изменению не подлежат**. Конвейер
ведётся по шагам с контролем сроков. Дальше - регистрация в журнале
договоров, загрузка скана, акты приёма-передачи и возврата (аренда
начисляется с даты акта приёма-передачи), дополнительные соглашения
с контролем изменяемых полей.

### Прочие разделы

- **Особый порядок** - заявки без тендера, заключения, публикации.
- **Инвестиции** - инвестиционные договоры, документы, приёмка, продление.
- **Участки** - земельные участки, публикация, решения, договоры.
- **Досье тендера** - автоматически собранная папка всех документов и событий
  с выгрузкой архивом.

## 8. Кабинет секретаря комиссии

### Журнал регистрации

Журнал по форме Приложения 12: номер по порядку, время сервера, заявка,
тип события (подана / отозвана). Журнал **только пополняется**: изменить или
удалить запись нельзя, номера идут строго подряд, после дедлайна приём
останавливается автоматически. До вскрытия в журнале видно, что заявка есть,
но цена в ней остаётся запечатанной.

### Заседание и вскрытие конвертов

Заседание открывается при кворуме - две трети состава с обязательным
присутствием председателя или его заместителя. Без кворума заседание
не открывается, и система не даст двинуться дальше. Секретарь отмечает
присутствующих и фиксирует отводы членов комиссии с основанием и заменой
резервным членом.

**Вскрытие** возможно не раньше назначенного времени заседания. После него
цены и документы заявок открываются комиссии - и только ей.

### Решения по заявкам

По каждой заявке - допустить или отклонить. Основание отклонения выбирается
**из закрытого перечня Правил**, произвольный текст не принимается. Голоса
членов комиссии («за» / «против», с особым мнением, если оно есть) вносятся
и подсчитываются здесь же.

### Протоколы

- **Протокол допуска** - формируется не позднее 3 рабочих дней после
  заседания, содержит все поля Правил, включая особые мнения. Формируется
  однократно.
- **Уведомление допущенных** - одной кнопкой: дата, время и место второго
  этапа плюс стартовая ставка, рассчитанная как максимум первоначальных
  предложений допущенных. Отправляется однократно.
- **Протокол итогов** - после завершения торгов по всем лотам, не позднее
  3 рабочих дней. Публикуется в течение 2 рабочих дней, публичный доступ -
  6 месяцев.
- **Протокол о несостоявшемся тендере** и **протокол о победителе № 2**.

### Ведение торгов

Панель торгов: открыть комнату лота, объявить старт, продлить таймер (один
раз на 15 минут), огласить первоначальное предложение отсутствующего
участника, отметить неявку, завершить торги. После итогов - внести ссылку
на запись.

## 9. Кабинет члена комиссии

Компактный кабинет: тендеры, по которым идёт допуск, состав комиссии
с указанием кворума и ролей (председатель, заместитель, члены, резервные),
и голосование по заявкам.

Перед заседанием член комиссии подаёт **декларацию о конфликте интересов**:
конфликта нет либо есть, с описанием. При конфликте оформляется отвод
большинством голосов, а место занимает резервный член.

Голос - только «за» или «против», третьего варианта в системе нет. Голос
подтверждается диалогом и **после подачи не меняется**: он вносится
в протокол. Можно приложить особое мнение - оно попадает в протокол допуска.
Решение принимается большинством присутствующих.

---

## 10. Кабинет финансового блока

### Подтверждение гарантийных взносов

Банковской интеграции нет: оператор вводит сумму и дату поступления
по банковской выписке. Взнос равен месячной ставке лота и должен поступить
не позднее чем за два рабочих дня до первого этапа. После подтверждения
статус заявки меняется, и участник видит это у себя.

### Депозитная книга

Счета двух видов: «гарантийный взнос участника по лоту» и «депозит
по договору». Все движения - проводки: поступление, возврат, удержание,
зачёт, списание, восполнение. Книга ведётся двойной записью, и **баланс счёта
не может уйти в минус** - система отклонит такую операцию.

### Возвраты

Возврат гарантийного взноса оформляется **только по основанию из перечня
Правил** (шесть случаев) и в срок не более 15 рабочих дней. У победителя и
участника № 2 - свои правила. При уклонении взнос удерживается.

### Депозит по договору

Депозит равен месячной арендной плате и вносится в течение 10 рабочих дней
с заключения договора. Виден размер, внесённая часть и остаток к внесению.
При удержании из депозита система ставит нанимателю обязательство восполнить
его, и это попадает в его раздел «Мои сроки».

## 11. Кабинет Правления

Сюда попадают заявки особого порядка - но **только после заключения
профильного подразделения**. Без заключения система решение принять не даст.

Решение: предоставить в особом порядке, отказать либо направить в общий
порядок (в тендер). Решение вносится в реестр и после принятия не изменяется.
По итогам формируется протокол решения (PDF), результат с обоснованием
публикуется на портале.

Здесь же рассматриваются заявки инвесторов на земельные участки.

## 12. Администрирование

### Пользователи и роли

Список учётных записей, назначение и отзыв ролей. Каждое изменение - в журнал
аудита. Учётную запись можно отключить: человек теряет вход и уже открытые
сессии, но его заявки, договоры и депозит сохраняются; запись можно включить
обратно. Сброс пароля выдаёт одноразовый пароль, который показывается один
раз и нигде не хранится.

### Справочники

- **МРП по годам** - от него считается базовая ставка.
- **Коэффициенты Приложения 4** - версионируются датой вступления в силу:
  добавляется новая версия, прежняя остаётся и продолжает объяснять прошлые
  расчёты.
- **Производственный календарь РК** - праздничные дни. По ним считаются все
  «рабочие дни» из Правил; выходные учитываются сами.

Справочники не удаляются: правка - это новая версия, а не переписанная
история.

### Цепочка аудита

Журнал изменений связан хеш-цепочкой. Фоновая проверка регулярно сверяет её
и показывает результат: цепочка цела или разорвана, и с какой записи
начинается расхождение. Разрыв означает, что данные меняли в обход журнала.

## 14. Особый порядок: аренда без тендера

Правила допускают предоставление имущества без торгов по закрытому перечню
из **13 категорий**. Порядок такой:

1. **Заявка** по форме Приложения 3: категория из перечня, объект, цель
   использования, срок, обоснование, документы. Обоснование публикуется вместе
   с результатом - это стоит учитывать при заполнении.
2. **Заключение уполномоченного подразделения** - до 15 календарных дней.
3. **Решение Правления** - предоставить, отказать или направить в общий
   порядок. Без заключения подразделения решение невозможно.
4. **Публикация** результата с обоснованием - в течение пяти рабочих дней,
   доступ шесть месяцев.

**Конкуренция заявок.** Если на один объект претендуют несколько заявок,
система это отслеживает. По части категорий при двух и более заявках вопрос
автоматически уходит в общий порядок - то есть в тендер. По инвестиционной
категории приоритет у большего объёма инвестиций; если суммы сопоставимы,
выбор остаётся за Правлением, и система об этом прямо пишет.

По каждому решению собирается **досье**: заявка, её документы, заключение,
решение и публикации. Хранится не менее трёх лет.

## 15. Инвестиционные договоры и льготы

### Инвестиционные договоры

Для проектов, где арендатор вкладывается в объект. Требования, которые
система проверяет, а не просто напоминает:

- обязательный комплект документов (смета, график, заключение оценщика,
  гарантия исполнения) - **без него договор не подписывается**;
- **срок не более семи лет**;
- продление на 3 года - отдельным действием с фиксацией в реестре;
- приёмка вложений оформляется актами: видно, сколько принято из заявленного
  объёма и когда обязательство исполнено полностью;
- ставка и её обоснование считаются сервером по коэффициентам и публикуются.

### Льготные схемы

Три схемы: оборудование в образовательном процессе, спин-офф университета,
социальный арендатор. Условия каждой проверяются системой - например, льгота
по образовательному оборудованию применяется только по согласованию Учёного
совета (с указанием даты), а спин-офф обязан вести не менее пяти кредитов
в семестр. Не выполнено условие - льгота не применится, и система объяснит,
чего не хватает.

## 16. Земельные участки

Отдельный, упрощённый порядок:

1. Организатор заводит объект вида «Земельный участок» и заполняет его
   характеристики: кадастровый номер, разрешённое использование, назначение,
   ожидаемый объём инвестиций.
2. **Публикация** - участок становится виден инвесторам на портале.
   Снять публикацию нельзя.
3. **Заявка инвестора** подаётся из кабинета участника: проект, объём
   инвестиций, срок.
4. **Решение Правления** - предоставить участок или отказать. Решение
   необратимо.
5. **Договор землепользования** формируется по данным заявки, ставку считает
   тот же калькулятор.

В договоре на участок обязательно закрепляются **особые условия - запрет
залога участка и возводимых на нём зданий**. Эти условия неизменяемы: система
не даст составить договор без них и не позволит их потом переписать.

## 17. Уведомления и контроль сроков

### Центр уведомлений

Типы уведомлений: приглашение на аукцион, заявка отклонена, опубликован
протокол, тендер изменён, тендер отменён, предложение второму месту, решение
по особому порядку, просрочено обязательство.

Каждое процессуальное уведомление - не просто сообщение в интерфейсе,
а запись с зафиксированным временем и получателем: это доказательство того,
что извещение было направлено.

### «Мои сроки»

Каждое событие процесса порождает обязательство с конкретной датой и ссылкой
на пункт Правил: оформить протокол допуска, уведомить допущенных, составить
договор с победителем, вернуть подписанный договор, внести депозит, вернуть
гарантийный взнос, опубликовать результат и так далее.

Ближайший срок виден прямо в шапке на каждой странице. Просроченные помечены
отдельно, и по ним приходит уведомление.

**Все «рабочие дни» считаются по производственному календарю Республики
Казахстан** - с учётом праздников.

## 19. Отчётность

Раздел доступен организатору, финансовому блоку, Правлению и администратору.
Три реестра за произвольный период:

- **Решения** - решения по особому порядку и земельным участкам;
- **Договоры** - договоры со статусами и основаниями;
- **Поступления** - движения по депозитной книге.

Реестр показывает записанные системой факты. Любой реестр **выгружается
в CSV** и открывается в Excel. Если записей слишком много, на экране
показывается первая часть, а полный список - в выгрузке; система об этом
предупреждает.

## 20. Как система защищает честность процедуры

Это не декларация, а перечень технических ограничений: перечисленное
не «не рекомендуется», а невозможно сделать через портал.

- **Цены запечатаны.** До вскрытия конвертов ценовые предложения зашифрованы
  и недоступны никому, включая организатора и администратора.
- **Журнал регистрации только пополняется.** Записи нельзя изменить или
  удалить, номера идут подряд, время - серверное.
- **Дедлайны стережёт база данных.** Подача после срока отклоняется на самом
  нижнем уровне, а не проверкой в интерфейсе.
- **Шаг торгов и таймер считает сервер.** Ставка ниже минимальной
  не принимается; продлить таймер второй раз невозможно.
- **Переходы статусов ограничены.** Тендер, договор или заявка переходят
  только в те состояния, которые предусмотрены Правилами.
- **Перечни закрыты.** Основания отклонения, основания возврата взноса,
  категории особого порядка - фиксированные списки без варианта «прочее».
- **Каждое изменение пишется в журнал аудита**, связанный хеш-цепочкой:
  правка в обход журнала обнаруживается автоматической сверкой.
- **Двойная запись в депозитной книге** и запрет отрицательного остатка.
- **Один объект не может быть сдан дважды** на пересекающийся период.
- **Публикации снимаются автоматически** ровно через шесть месяцев, а сами
  документы остаются в досье с защитой от удаления.

## 21. Q&A

**Нужно ли регистрироваться, чтобы посмотреть объявления?**
Нет. Объявления, свободные площади, земельные участки, опубликованные
протоколы и публикации особого порядка открыты всем.

**Кто увидит мою цену до вскрытия?**
Никто. Ни организатор, ни администратор портала.

**Что будет, если я подам заявку в последнюю минуту?**
Приём закрывается по серверному времени ровно в указанный срок. Опоздавшую
заявку система не примет. Учитывайте время на загрузку документов.

**Можно ли изменить поданную заявку?**
Нет. До дедлайна заявку можно отозвать (отзыв фиксируется в журнале) и подать
заново, если приём ещё открыт.

**Сколько стоит участие?**
Само участие бесплатно. Вносится гарантийный взнос, равный месячной стартовой
ставке лота; он возвращается по основаниям Правил в срок до 15 рабочих дней.

**Что если я не смогу присутствовать на торгах?**
Система объявит ваше первоначальное предложение. Но повышать ставку за вас
никто не будет - фактически вы участвуете только своей стартовой ценой.

**Я выиграл, но передумал подписывать договор.**
Гарантийный взнос удерживается, вы попадаете в реестр уклонившихся, и ваши
заявки в будущих тендерах будут отклоняться автоматически. Договор
предлагается участнику № 2.

**Что делать, если пропал интернет во время торгов?**
Вернитесь в комнату - состояние торгов восстановится. Но таймер во время
вашего отсутствия не останавливается.

**Почему система отказала в действии?**
Она пишет причину словами Правил прямо в сообщении об ошибке. Если
формулировка непонятна, обратитесь к организатору - в сообщении указан пункт
Правил.

**Как долго доступны протоколы?**
Публично - шесть месяцев с публикации. Дальше они остаются в досье тендера
и доступны участникам в кабинете.

**Можно ли пользоваться сайтом с телефона?**
Да, интерфейс приспособлен к узким экранам. Для торгов и загрузки документов
удобнее компьютер.

## 22. Словарь терминов

| Термин                         | Что значит                                                                                             |
| ------------------------------ | ------------------------------------------------------------------------------------------------------ |
| **Тендер**                     | Процедура, по которой университет выбирает арендатора                                                  |
| **Лот**                        | Один объект с условиями аренды внутри тендера; торги идут по каждому лоту отдельно                     |
| **Объявление**                 | Публичный документ с условиями тендера, сроками и составом лотов                                       |
| **Тендерная документация**     | Приложенные к объявлению материалы, которые нужно изучить до подачи заявки                             |
| **Вскрытие конвертов**         | Момент, когда комиссия открывает поданные заявки и цены становятся ей видны                            |
| **Первоначальное предложение** | Цена, указанная в заявке до торгов                                                                     |
| **Допуск**                     | Решение комиссии о том, что заявка соответствует требованиям и участник идёт на торги                  |
| **Стартовая ставка торгов**    | Наибольшее из первоначальных предложений допущенных участников по лоту                                 |
| **Шаг торгов**                 | Минимальная надбавка к текущему максимуму - 5 % от стартовой ставки                                    |
| **Гарантийный взнос**          | Обеспечение участия, равное месячной стартовой ставке лота                                             |
| **Депозит**                    | Обеспечение по договору, равное месячной арендной плате                                                |
| **Уклонение**                  | Неподписание договора победителем в срок; влечёт удержание взноса                                      |
| **Участник № 2**               | Занявший второе место; получает право на договор при уклонении победителя                              |
| **Протокол**                   | Документ, фиксирующий решение комиссии; формируется системой                                           |
| **Особый порядок**             | Предоставление имущества без тендера по закрытому перечню категорий                                    |
| **Кворум**                     | Минимальное число членов комиссии для законного заседания - две трети с председателем или заместителем |
| **Отвод**                      | Исключение члена комиссии из рассмотрения вопроса при конфликте интересов                              |
| **МРП**                        | Месячный расчётный показатель; от него считается базовая ставка аренды                                 |
| **Досье**                      | Автоматически собранная папка всех документов и событий по тендеру или решению                         |
| **Аудит**                      | Защищённый журнал всех изменений в системе                                                             |

## 23. Чего в системе пока нет

- **Электронной цифровой подписи нет.** Договоры печатаются, подписываются
  на бумаге, скан загружается в систему.
- **Банковской интеграции нет.** Поступление гарантийного взноса и депозита
  подтверждает оператор финансового блока по банковской выписке.
- **Уведомления пока только внутри портала.** Рассылка на электронную почту
  и в Telegram запланирована.
- **Единый вход с корпоративной учётной записью** ещё не настроен.
