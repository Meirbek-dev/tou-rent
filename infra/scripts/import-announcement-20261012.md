# Импорт объявления от 12 октября 2026 года

Источник: `D:\Projects\Объявление.docx`. Скрипт создаёт черновик с номерами
лотов 1, 8 и 11, сроком аренды 12 месяцев, месячными ценами без НДС 31 720,
32 113 и 1 409 124 тенге. Гарантийный взнос равен месячной стартовой цене.
Приём заканчивается 22.10.2026 в 18:00 UTC+5, вскрытие назначено на
23.10.2026 в 10:00 UTC+5. Дата торгов отсутствует и не заполняется.

Фиксированный ID черновика: `597f17a0-a579-4f46-a5ab-65f1bb97cf20`.
Повторный запуск только показывает существующий тендер; ошибки прерывают
транзакцию. Существующие объекты с совпадающими адресом и площадью используются
без изменения. Создание объектов, тендера и лотов проходит через штатный аудит.

На прод-сервере после получения скрипта через Git выберите реальный email:

```bash
cd ~/tou-rent
docker compose -f infra/compose/docker-compose.prod.yml exec -T postgres \
  psql -U tou_rent -d tou_rent -c "
SELECT u.email,u.full_name
FROM core.users u
WHERE u.is_active AND EXISTS (
  SELECT 1 FROM core.role_grants r
  WHERE r.user_id=u.id AND r.role IN ('organizer','admin')
)
ORDER BY u.full_name;"
```

Затем выполните импорт, подставив выбранный email:

```bash
docker compose -f infra/compose/docker-compose.prod.yml exec -T postgres \
  psql -U tou_rent -d tou_rent -v organizer_email='EMAIL_ОРГАНИЗАТОРА' \
  < infra/scripts/import-announcement-20261012.sql
```

Миграция и пересборка контейнеров не требуются. Черновик доступен в кабинете
организатора, а на публичном сайте появится после отдельной публикации.
До публикации прикрепите полный текст объявления в виде тендерной документации:
скрипт импортирует структурированные лоты, но не загружает Word/PDF в хранилище.
Специальные требования №11 сохранены в данных источника, что само по себе
не добавляет их в форму проверки заявки. Вопрос смешанных повторных и первичного
лотов, а также разница начала аренды в двух языковых версиях описаны в Q-028.

Локальная проверка выполнена 12.10.2026 с `organizer@tou.demo`: создан черновик
с тремя лотами, повторный запуск не изменил его и не создал дубликатов.
