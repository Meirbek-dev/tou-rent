# Указатель исторических A-ID

Новые допущения сюда не добавляются: неоднозначности идут в [QUESTIONS.md](QUESTIONS.md),
архитектурные решения — в [adr/](adr/). Этот файл сохраняет только A-ID, на которые еще
ссылаются код, миграции или действующая документация. Подробная история доступна в Git.

- **A-001 — Vite+.** Web использует `vp`, oxlint/oxfmt и tsgo вместо первоначального набора инструментов.
- **A-003 — Rust на Windows.** Rust проверяется в Linux-контейнере с общим Cargo cache; линковка на Windows-хосте не требуется.
- **A-004 — локализация.** Русский — базовая локаль; kk/en обязательны, но допускают черновой перевод до редакторской вычитки.
- **A-006 — живой CI.** GitLab pipeline еще не подтвержден на реальном runner; активная работа — T45.
- **A-007 — Git hooks.** Используется диспетчер Vite+ и `.vite-hooks`, не lefthook; детали — ADR-0001.
- **A-010 — исходные справочники.** МРП, коэффициенты, календарь и тексты из недоступных приложений содержат TODO-ENGINEER; см. Q-001 и связанные вопросы.
- **A-011 — роль БД.** Приложение работает через `tou_rent_app` без `BYPASSRLS`; владелец схемы используется только для миграций и явно ограниченных admin-команд.
- **A-017 — публичный реестр.** Фильтры применяются во фронте поверх страницы до 100 тендеров; серверный поиск нужен при росте объема.
- **A-020 — форма заявки.** Состав полей приложений приближен по ТЗ, размер одного файла ограничен 20 МБ; требуется сверка с оригиналами форм.
- **A-021 — интеграционные тесты.** Testkit требует `TESTKIT_DATABASE_URL`; локально может пропускаться, в CI пропуск считается ошибкой.
- **A-023 — realtime-уведомления.** Межпроцессная шина — Redis pub/sub, доставка до сокета — локальный broadcast; `delivered_at` заполняют только подтверждаемые внешние каналы.
- **A-024 — WebSocket в dev.** Из-за отсутствия upgrade в Nitro dev-клиент ходит прямо на api через `VITE_API_WS_HOST`; в production проксирует Caddy.
- **A-029 — deployment.** Публикация образов в Registry остается T48; `deploy.sh` запрещает деплой во время активных торгов, явный обход — `DEPLOY_FORCE=1`.
- **A-030 — e2e контура 1.** Старый сценарий разделен из-за десятидневного срока FR-303; переход на непрерывный путь учитывается в T68.
- **A-045 — очередь торгов.** Ходы идут по номеру заявки в журнале регистрации; внеочередная ставка отклоняется БД.
- **A-054 — реестр уклонистов.** До ответа заказчика запись действует бессрочно и блокирует новую заявку при регистрации.
- **A-055 — последствия уклонения.** Взнос удерживается, договор прекращается, право один раз переходит участнику № 2; третьего кандидата нет.
- **A-058 — публичный протокол.** Публикация и снятие однократны; публичный срок — шесть месяцев, копия остается в досье и доступна участникам.
- **A-060 — ключ цен.** `PRICE_ENCRYPTION_KEY` хранится отдельно от БД и дампов; потеря ключа делает предложения нечитаемыми. Ротация входит в T47.
- **A-061 — почасовая ставка.** До ответа на Q-022: база 2 МРП/час, коэффициенты Прил. 4, без площади, с нижней границей 2 МРП/час.
- **A-062 — почасовой взнос.** Для настоящего почасового лота взнос равен ставке за час, умноженной на объем часов.
- **A-063 — CI и миграции.** Гейты обязательны; примененные миграции не переписываются, G4 проверяет только новые миграции MR.
- **A-065 — e2e контура 2.** Часть сценариев пока стартует с подготовленных `demo-*` состояний; замена полным путем — T68.
- **A-066 — категории особого порядка.** Устойчивые ID — номера 87.1–87.13; названия и требования требуют заполнения по Правилам (Q-009).
- **A-067 — заявитель особого порядка.** Использует права обычного внешнего участника; отзыв возможен до решения.
- **A-068 — уполномоченное подразделение.** До ответа заказчика эту функцию выполняет `organizer`; см. Q-009/Q-014.
- **A-071 — конкуренция инвестиций.** Сравниваются активные заявки одной категории на один объект; порог сопоставимости по умолчанию 5 % (Q-013).
- **A-072 — роли инвестдоговора.** Договор ведет organizer, приемку оформляет secretary, продление — board; распределение требует подтверждения.
- **A-073 — неполный инвестконтур.** Компенсация, повышенная плата и реестр ненадлежащих инвесторов ждут данных Q-014/T56.
- **A-075 — WORM.** Срок идет от события; dossiers хранятся не менее 5/3 лет, Object Lock — compliance, автоматического удаления нет; детали — ADR-0004.
- **A-076 — публикации особого порядка.** Отдельные неизменяемые записи доступны шесть месяцев; состав и срок ждут ответа Q-015.
- **A-077 — земельные участки.** Назначения и условия п. 104–107 пока справочные placeholders; см. Q-016.
- **A-078 — допсоглашения.** Защищены ставка, объект, срок и наниматель; допустимые изменения требуют сверки с п. 125 (Q-017).
- **A-079 — отчетность.** Реализованы реестры фактов и CSV без выдуманных печатных форм; требуемый состав уточняется Q-012.
- **A-080 — e2e контура 3.** Сценарии используют подготовленные площадки и временную отметку инвестиционной категории; переход — T68.
- **A-092 — WS в приемочном стенде.** Production-сборка без Caddy использует `VITE_API_WS_HOST`; настоящий production остается same-origin.
- **A-093 — RustFS provisioning.** Бакеты/Object Lock создает AWS CLI, IAM — клиент RustFS `rc`; оба шага обязательны.
- **A-094 — проверка Object Lock.** Compliance и запрет удаления проверены локально на prod-compose; повторить после первого реального деплоя T49.
- **A-095 — сироты dossiers.** Файл без записанных метаданных остается в WORM-бакете, но недостижим через приложение; ключ фиксируется в warn-логе.
- **A-096 — старые checksum миграций.** После исторической правки комментариев существующим БД нужен `resync-migration-checksums.sh --apply` до migrate.
- **A-098 — Object Lock в dev.** Dev использует governance на сутки для очищаемости; production — compliance на пять лет.
- **A-099 — лимиты памяти.** Текущие `mem_limit` рассчитаны на хост 16 ГБ без замеров; уточнить по T59 и реальному cgroup.
- **A-100 — rollback.** `deploy.sh` откатывает код, но не схему; несовместимые изменения требуют expand/contract миграций.
- **A-101 — UID Redis.** Контейнер закреплен за `999:999`; при смене образа UID нужно перепроверить.
- **A-102 — health worker.** У `jobs` нет корректной healthcheck; живость видна по логам, отдельный heartbeat пока не реализован.
- **A-106 — залы с месячной ценой.** Почасовой режим использования не делает лот почасовым, если объявление торгует месячную цену; см. Q-022.
- **A-109 — бренд.** Палитра получена из переданных логотипов, `SITE_ORIGIN` закреплен как `https://rent.tou.edu.kz`; нужна сверка с брендбуком.
