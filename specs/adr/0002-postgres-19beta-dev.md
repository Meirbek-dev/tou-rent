# ADR-0002: PostgreSQL 19 beta во всех контурах до первого production deployment

Статус: accepted · 2026-08-06 · изменено решением T61 от 2026-08-09

## Контекст

Первоначально планировались PostgreSQL 19 beta в dev и стабильный PostgreSQL 18 в
production. Это создавало непроверенный разрыв между средами. Первый production deployment
еще не выполнялся, а текущая схема не использует функции новее PostgreSQL 18.

## Решение

- Dev, CI и `docker-compose.prod.yml` используют один образ `postgres:19beta2`.
- Первый production deployment не выполняется на beta случайно: перед T49 инженер либо
  подтверждает этот образ, либо одним изменением переводит все контуры на подходящий GA.
- Миграции сохраняют совместимость с PostgreSQL 18; `uuidv7()` доступен в 18.
- Данные монтируются в `/var/lib/postgresql`, чтобы штатный `pg_upgrade` работал с
  версионированными подкаталогами образов 18+.

## Следствия

Среды остаются паритетными, но beta-СУБД нельзя считать production-ready по умолчанию.
Выбранную перед T49 версию нужно закрепить digest/tag во всех compose и подтвердить
восстановлением из backup.
